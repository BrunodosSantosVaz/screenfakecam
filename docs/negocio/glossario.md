# Glossário

| Termo | Significado |
| --- | --- |
| Visor | A área da tela que mostra a imagem escolhida como se fosse a câmera. A imagem fica parada: nada é capturado sem o usuário apertar o obturador. |
| Enquadramento | A parte da imagem que aparece no visor: depende do zoom e da posição (RN-0001, RN-0002). |
| Zoom | Quanto a imagem está ampliada no visor, de 1× (imagem inteira) a 4× (RN-0001). |
| Seletor de fotos | A tela do próprio Android para escolher uma imagem; dá ao app acesso só à imagem escolhida (RN-0003). |
| Obturador | O botão que "tira a foto" do enquadramento atual: a foto é o trecho visível, na resolução da imagem decodificada (RN-0004), e só sai quando ele é apertado (RN-0005). |
| Código | QR code ou código de barras lido de uma imagem; o app mostra o tipo e o texto completo (RN-0006). |
| Abrir link | Abrir no navegador do usuário um texto lido que seja `http`/`https`, só por toque (RN-0007). |
| Foto | Arquivo JPEG novo criado pelo obturador; a imagem escolhida nunca muda (RN-0005). |
| Imagem decodificada | `Picture<ImageBitmap>`: imagem carregada em memória por `AndroidPictureLoader`, com orientação EXIF e redução possível; suas dimensões são a base do recorte, sem alterar o arquivo original. |
